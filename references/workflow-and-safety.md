# Safe Browser Workflow
## Before Grading
1. Confirm the active course, class, assignment, and pending filter.
2. Record the assignment prompt and any visible full-score rules.
3. Protect prior work: do not edit already-completed rows unless asked.
4. Check available disk space and create one unique temporary directory outside the repository if analysis assets are needed.
## Previewing Reports
1. Open the student's attachment by clicking the attachment name.
2. Use Chaoxing's preview tab. Do not use the download button.
3. Wait until the document title and page controls have rendered. A loading page that momentarily reports one page is not reliable.
4. Inspect cover identity, required sections, code, results, analysis, and reflection.
5. If OCR is required, use only rendered preview pages in the temporary directory. Delete them when the submission or batch is complete.
6. Close preview tabs promptly to avoid accumulating browser resources.
## Submission
1. Enter the score and wait for the total-score field to update.
2. If a comment is required, open the homework-comment editor, write the issue-specific feedback, and verify the text appears.
3. Use the grading action specified by the user's policy.
4. Wait for the row to show completed and the intended score; do not equate a click with success.
5. Avoid double-submitting after an uncertain click. Refresh and inspect status first.
## Duplicate and Identity Checks
- Compare the roster name and student ID with the cover and attachment name.
- Track attachment object IDs or file names across a batch.
- If two students share the same file, inspect both rows before assigning scores.
- Do not infer misconduct solely from similar wording. Describe the observable duplication or mismatch.
## Recovery
- If a preview opens but stays blank, return to the grading list and reopen it.
- If two attachments exist, inspect all visible attachments and the primary report.
- If a grading page times out, refresh once, inspect status, then continue.
- If the page reports session timeout, reopen the list through the course navigation rather than fabricating URLs.
## Final Audit
- Revisit each class.
- Verify every assignment card's pending count is zero.
- Confirm no rows remain in "待批阅".
- Confirm no original submissions were saved locally.
- Remove the dedicated temporary directory.
- Report any skipped, blocked, or uncertain submissions explicitly.
